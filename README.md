# ЭХО — лендинг онлайн-бутика женской одежды (Иркутск, Ангарск)

Одностраничный адаптивный сайт для [@tvoye.echo](https://www.instagram.com/tvoye.echo/). Готов к публикации на любом статическом хостинге: залить содержимое папки в корень сайта.

## Структура
```
index.html          — страница (10 блоков) + JSON-LD (ClothingStore, WebSite, FAQPage)
css/style.css       — стили
js/main.js          — меню-бургер, слайдер отзывов, хотспоты образа, переключатель цветов брюк, видео
img/                — WebP (sm/lg) + JPEG-фолбэк, иконки, og.jpg
video/              — сжатые H.264 MP4 (faststart)
robots.txt, sitemap.xml, llms.txt, site.webmanifest, .htaccess
seo/keywords.md     — семантическое ядро и план продвижения
```

## Блоки
1. Hero — «ЭХО / Это Хочется Одеть», H1 с гео-ключами, кнопки в Direct
2. Что такое ЭХО — манифест, три принципа Э·Х·О
3. Сборный образ в наличии — интерактивные точки на фото
4. Эко-шубы под норку — видео примерки, предзаказ 5 дней
5. Капсула на зиму — брюки «ёлочка» (переключатель цветов), футболка-платье, жакет
6. Подарок — пробник духов @pocherk_perfume, видео со звуком
7. Как купить — 4 шага
8. Отзывы — слайдер (свайп, стрелки, точки, автопрокрутка)
9. FAQ
10. Финальный призыв + футер

Карты нет — по ТЗ.

## Перед публикацией
- Заменить `https://tvoye-echo.ru/` на реальный домен (index.html, robots.txt, sitemap.xml, llms.txt).
- **Отзывы в блоке 8 — демо-тексты для макета** (помечены `data-demo`). Заменить на реальные отзывы клиенток.
- Шрифты Cormorant Garamond и Manrope подключены с Google Fonts; при желании можно разместить локально.

## Совместимость
Safari iOS 13+, Chrome/Android, Firefox, Edge, Samsung Internet. WebP с JPEG-фолбэком, `playsinline` для видео на iPhone, `env(safe-area-inset-*)` для «чёлки», `prefers-reduced-motion`.
