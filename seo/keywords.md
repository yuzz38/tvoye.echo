# Семантическое ядро и SEO/GEO-план — ЭХО (tvoye.echo)

Регион: Иркутск, Ангарск (Яндекс — регион «Иркутская область»).
Частотность — ориентир, перед запуском проверить в Яндекс Wordstat.

## 2. Информационно-коммерческие (трафик + доверие)
- с чем носить брюки ёлочка → описание «сочетаются с любой базой»
- что надеть зимой стильно / капсула на зиму → заголовок «Капсула на зиму»
- эко шуба или натуральная норка → блок эко-шубы («без компромиссов»)
- нишевая парфюмерия Иркутск / пробник духов в подарок → блок «Подарок»

## 3. Брендовые
ЭХО одежда, tvoye.echo, твоё эхо Иркутск, эхо бутик, «это хочется одеть».

## 4. GEO (генеративные ответы: Алиса, YandexGPT, ChatGPT, Perplexity)
- `llms.txt` в корне — краткие факты о бренде для ИИ-ассистентов.
- JSON-LD: ClothingStore + areaServed (Иркутск, Ангарск) + OfferCatalog + FAQPage.
- FAQ написан в формате «вопрос — прямой ответ», который ИИ цитируют дословно.
- robots.txt открыт для GPTBot, OAI-SearchBot, PerplexityBot, ClaudeBot, Google-Extended.
- meta geo.region / geo.placename.

## 5. Что сделать после публикации
1. Заменить домен `tvoye-echo.ru` на реальный (index.html, robots.txt, sitemap.xml, llms.txt).
2. Добавить сайт в Яндекс.Вебмастер и Google Search Console, отправить sitemap.xml; в Вебмастере указать регион «Иркутск».
3. Зарегистрировать компанию в Яндекс Бизнесе и 2ГИС как онлайн-магазин «ЭХО» без адреса, со ссылкой на сайт — главный локальный сигнал.
4. Заменить демо-отзывы реальными (скриншоты/цитаты из Direct с согласия клиенток).
5. Поставить Яндекс.Метрику, цели на клики по ссылкам `ig.me/m/tvoye.echo`.
6. Ссылка на сайт в шапке профиля Instagram и в Telegram.
